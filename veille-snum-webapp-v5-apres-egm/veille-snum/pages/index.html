Collecte et sélection de la veille SNUM

La collecte se fait en deux temps sur GitHub Actions. D’abord, elle consulte des sources publiques dans la période indiquée et publie sur cette page les titres trouvés. Vous gardez ensuite les titres utiles, puis Albert rédige leurs résumés et le paquet V519 est publié. Relisez enfin chaque article, gardez ou écartez-le, corrigez sa thématique si besoin, puis exportez le JSON V519. Les faits ne sont pas certifiés automatiquement : vérifiez chaque source avant diffusion.

Connexion à GitHub

Un jeton GitHub personnel est nécessaire seulement pour lancer une collecte ou repêcher un article. Sans jeton, la sélection du paquet publié reste entièrement utilisable. Le jeton reste dans cette page : il n’est ni enregistré dans le navigateur, ni ajouté à l’adresse, ni inclus dans les exports, et disparaît à la fermeture ou au rechargement de la page. Le jeton Albert reste dans les secrets du dépôt et n’apparaît jamais ici.

Lancer une collecte

La collecte remplace ce que publie cette page pour toutes les personnes qui la consultent ; la collecte précédente reste consultable dans les archives. Par défaut, elle s’arrête aux titres trouvés (trois à quatre minutes) : vous choisissez ensuite les articles à faire résumer. Gardez cette page ouverte pendant la collecte : son avancement s’affiche ici, et le jeton disparaît si vous la rechargez.

Sauf mention contraire, tous les champs sont obligatoires.
