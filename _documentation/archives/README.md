# Archives du projet Newsletter SNUM

Ce dossier conserve les versions antérieures sans les exposer comme fichiers actifs à
la racine du dépôt.

- `releases/` contient les prompts, notices, rapports, paquets ZIP et ressources propres
  aux V5.12 à V5.17 ;
- `legacy-monolith/` contient l’ancien dispositif monolithique et progressif ;
- les dossiers `installation-*` et `validation-*` voisins conservent les résultats des
  recettes historiques.

Ces fichiers servent uniquement à l’historique et au retour d’expérience. Pour une
nouvelle installation, utilisez exclusivement les fichiers V5.18 présents à la racine.
